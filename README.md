# DevSoc Minecraft Modpack

## How to install

1. Download Prism Launcher from [here](https://prismlauncher.org/).
2. Download the latest release of the modpack from [here](https://github.com/devsoc-unsw/modpack/releases/latest).
3. Open Prism Launcher and drag the downloaded `.mrpack` file into the launcher window.
4. Follow the prompts to install the modpack.
5. Profit!
